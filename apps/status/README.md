# Service status

Four Atlassian Statuspage summaries, initially GitHub, Cloudflare, Discord and OpenAI.
The four link defaults work without saved settings. Clear a page with Remove to hide its
row. Refresh choices are 1, 5, 15 and 30 minutes; the default is 5 minutes. OK refreshes all
enabled pages. Affected services come first, with their number in the header. Maintenance
counts as affected. Unknown data has its own state and does not count as a confirmed outage.

The app retains the last good name, indicator and description for each source. Source
addresses are represented by hashes in the snapshot. All four answers share one store value:
including NVS record overhead, the snapshot and four maximum-length links plus the pace
fit the 2 KB budget. Failed or malformed answers preserve the previous good values.
