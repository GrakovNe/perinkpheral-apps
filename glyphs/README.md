# Glyph packs

Letters beyond ASCII for the device's fonts. Made by `tools/fontgen/mkpack.py` of the
[perinkpheral](https://github.com/GrakovNe/perinkpheral) repository.

The packs are font software under the SIL Open Font License 1.1, not under the MIT license of
this repository.

| Font | Copyright | License |
|---|---|---|
| Departure Mono | 2022-2024 Helena Zhang (helenazhang.com) | `OFL-DepartureMono.txt` |
| Jersey 10, 15, 25 | 2023 The Soft Type Project Authors (https://github.com/scfried/soft-type-jersey) | `OFL-Jersey.txt` |

Modified: the Cyrillic letters of the Jersey faces are not part of the original fonts. They are
built from the fonts' Latin glyphs by `tools/fontgen/jersey_cyrillic.py`.
